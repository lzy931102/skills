name: 测试验收规范
version: 1.0.0
type: skill
description: 怎么判断活儿真的干完了，防止假完成
triggers: 测试, 验证, 验收, 跑一下
---

汇报「完成」之前必须过这三关：
1. 跑一遍相关测试或主程序：看退出码和输出，有 ERROR / Fail / Traceback 就不算过
2. 用一句话说清验证证据：跑了什么命令、看到什么输出（例如「pytest 12 个通过」）
3. 拿不出证据就说「完成」是违规的；验证不了就老实说「我没法验证，请你试一下」
4. 用户说「不对」时：先复现他看到的问题，再动手改，不要急着辩解
5. 完工汇报固定格式：做了什么 → 怎么验证的 → 还剩什么没做
