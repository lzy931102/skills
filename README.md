# 王董事长的技能仓库 🎋

这是 Desktop Agent（桌面助手）的**私人技能仓库**——装到哪台电脑，助手就学会哪些本事。

## 里面有什么

### 技能包（skills/）——给 AI 的"操作手册"

纯文本说明，AI 读了就知道该怎么干活，不执行任何代码，绝对安全：

| 技能包 | 作用 |
|---|---|
| 改代码步骤规范 | 让 AI 改代码前先读懂、改完自查，不瞎改 |
| 命令行操作规范 | 教 AI 安全地跑命令，危险命令先确认 |
| 报错排查流程 | 程序报错时按套路排查，不乱猜 |
| Python项目规范 | 写 Python 代码的规矩（依赖、结构、命名） |
| 测试验收规范 | 干完活先跑测试，测试过了才算完 |

### 连接器（connectors/）——给 AI 的"真工具"

`dev_tools.py`（开发者工具箱）：让助手能列文件、读文件、写文件（自动备份）、跑命令。
其中跑命令每次都要你点头确认，写文件会自动留 .bak 备份，破坏性命令直接拦截。

## 怎么安装

**方法一（最简单）：让 AI 自己装**

对桌面助手说：

> 帮我从 https://github.com/lzy931102/skills 安装技能包

**方法二：手动装**

1. 打开桌面助手的「插件」面板
2. 切到「🧭技能」或「🔌连接器」标签
3. 点「安装」，选中下载的文件夹或 zip
4. 点「刷新」，看到绿色就是装好了
